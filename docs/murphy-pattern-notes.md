## 二、章节框架

### 第4章 趋势与缺口

- 趋势：由依次抬高/降低的高点和低点定义；分为主要、次级、短期趋势。
- 支撑与阻力：是区域不是精确点位；突破后支撑变阻力、阻力变支撑。
- 趋势线：连接依次抬高的低点或依次降低的高点；通道是趋势线的平行线。
- 回撤：常见 33%、50%、66% 回撤，属于概率区域而非精确点位。
- 缺口：突破缺口、持续缺口、衰竭缺口；岛形反转由两个方向相反的缺口构成。

### 第5章 反转形态

- 头肩顶 / 头肩底：三个峰/谷，中间最高/最低；颈线突破确认。
- 三重顶 / 三重底：三次测试相近价位；中间两个转折点构成颈线。
- 双顶 / 双底：M 头 / W 底；两个顶/底相近，颈线突破确认。
- 圆弧顶 / 圆弧底：趋势逐步衰减、成交量先缩后放，需要较长时间。
- V 形反转：急速单边后的尖锐反转，通常需要回踩确认。
- 共同规则：必须有前置趋势；形态越大、时间越长，后续意义通常越大；突破颈线需要量能；用形态高度测算目标；跌破形态极值失效。

### 第6章 持续形态

- 对称三角形：高点降低、低点抬高，方向待突破；通常沿原趋势方向突破。
- 上升三角形：水平压力 + 抬高低点，偏多。
- 下降三角形：水平支撑 + 降低高点，偏空。
- 旗形 / 三角旗：快速趋势后的短暂窄幅整理；整理缩量，突破放量。
- 上升楔形：两条边都向上但收敛，偏空；下降楔形：两条边都向下但收敛，偏多。
- 矩形：水平区间反复震荡，突破后按箱体高度测算。
- 共同规则：整理期通常缩量，突破需要量能；用旗杆高度或形态最宽处测算目标。

### 第12章 日本蜡烛图

- 十字星：多空均衡，必须等下一根 K 线确认。
- 刺透形态 / 乌云盖顶：两根 K 线的反转组合。
- 早晨之星 / 黄昏之星：三根 K 线的反转组合。
- 上升三法 / 下降三法：长实体 + 三根小实体整理 + 同方向长实体，属于持续形态。
- 共同规则：蜡烛图必须结合前置趋势、支撑阻力和后续确认，不能单独使用。

## 五、统一确认清单

1. **前置趋势**：反转形态必须先有上涨/下跌趋势；持续形态必须处于趋势中。
2. **形态边界**：颈线、趋势线、箱体上下沿、旗面上下沿。
3. **突破确认**：收盘价突破，而不是盘中刺穿。
4. **量能**：突破放量更可靠；整理期缩量更符合持续形态。
5. **测算目标**：颈线 ± 形态高度、旗杆高度、箱体高度、三角形最宽处。
6. **失效条件**：重新站上/跌破形态关键点，或突破后快速回到形态内部。

## 六、本工具的限制

- 形态识别是规则近似，不是人工画线，也不是投资建议。
- 截图分析没有真实价格轴和成交量，只能按图内相对位置还原；量能会显示“截图未包含成交量”。
- A 股没有期货持仓量（open interest），本工具只用成交量确认，未实现持仓量分析。
- 形态测验的题干区域固定为最后 55 根，答案只在这 55 根内生成。
